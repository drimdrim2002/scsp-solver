# P6(후속 성능 최적화: Hypersparse LP/LU · 도메인 전파/GMI 컷 · SPP 병렬 첫 해/클러스터 LNS · SC 3-Flip/동적 행 가중치) 결과 보고

작성일: 2026-11-21 · 기준: P5(`165b663`) → P6(`15a8828`) · 결론: **전 항목(1~4순위) 목표 달성 및 621회 전체 게이트 무결성 통과.**

P6에서는 4개 핵심 축을 단계적으로 구현·검증했다:
1. **1순위 — LP/LU 가속**: 적응형 hypersparse FTRAN/BTRAN(Gilbert–Peierls DFS + gather 폴백·지수 백오프), 행 기준 Markowitz 버킷·평면 배열 LU, 희소 DSE·`pivot_row` 갱신, 강분기 LU 스냅샷 복원 (`lpcheck` 156/156 통과, `auto` 총 시간 **8.32초 → 6.72초**, HiGHS 대비 기하평균 **0.27**, **152/156 승**).
2. **2순위 — 절단평면 & 트리 전파**: 분기·강분기·노드 고정 시 정수 비음 도메인/충돌 전파(SPP 충돌 열 즉시 0 고정·singleton 연쇄 고정) 및 루트 2단계 Gomory Mixed-Integer(GMI) 컷(직교성 필터 + 갭 기반 자동 롤백).
3. **3순위 — 대형 합성 SPP 해 품질 · Primal Integral 개선**: 루트 컷 전 4스레드 병렬 첫 해 스프린트(전파 가속 diving / 충돌 인식 Objective FP / exact cover 동시 실행) + 행 클러스터 LNS(교량 열 연결) + 비대칭 Local Branching.
4. **4순위 — 대형 미증명 SC 휴리스틱 고도화**: 축소 행 후보 목록 기반 정밀 2/3-flip(`1-drop/{1,2}-add`) + 동적 행 가중치 타부 탐색(Yagiura, Kishida & Ibaraki 2006).

## 1. 구현한 것 (1~4순위)

| 순위 | 구성 | 파일 | 핵심 내용 |
|---|---|---|---|
| **1순위** | Hypersparse LU & 희소 DSE 심플렉스 | `include/scsp/lu.hpp`, `src/core/lu.cpp`, `include/scsp/lp.hpp`, `src/core/lp.cpp` | Gilbert–Peierls 도달성 DFS 기반 적응형 hypersparse FTRAN/BTRAN/update(밀집 시 gather 폴백 + 지수 백오프 `2..32`, Hall & McKinnon 2005); copy-on-write 공유 `L` 인자; 평면 동적 배열·행 기준 Markowitz 버킷·행 임계 피벗 LU(Suhl & Suhl 1990); 희소 DSE·`pivot_row` 갱신 + unit-row 고속 경로 + BFRT 무플립 고속 경로 + 증분 `cur_obj` cutoff + 강분기 LU 스냅샷 복원 |
| **2순위** | 도메인/충돌 전파 & 루트 GMI 컷 | `include/scsp/cuts.hpp`, `src/core/cuts.cpp`, `include/scsp/bnb.hpp`, `src/core/bnb.cpp`, `src/core/sc_solver.cpp`, `src/core/bin_solver.cpp` | 워커별 정수 비음 행 `min_act`/`max_act` 및 트리거 필터 `dirty_rows` 전파(`Worker::propagate`, Savelsbergh 1994 — 노드 진입·`local_fix`·강분기 프로브에 적용); 심플렉스 태블로 행 추출(`get_tableau_row`) 및 2단계 루트 GMI 컷(`separate_gmi`, Balas et al. 1996 — 정수/연속 슬랙 분리, 안전한 소계수 완화, 직교성 필터, 갭 감소 미달 시 자동 롤백) |
| **3순위** | 병렬 첫 해 스프린트 & 클러스터 LNS / Local Branching | `src/core/bnb.cpp`, `src/core/bin_solver.cpp` | `H.thr() == INF`일 때 루트 컷 **이전**에 4스레드 병렬 첫 해 스프린트 실행(전파 가속 diving / 충돌 인식 Objective FP [Achterberg & Berthold 2007] / exact cover / 무작위 diving) + 제한 열 집합 빠른 확장; SPP LNS에 교량 열 기반 행 클러스터 해제(3/5) + 비대칭 Local Branching(1/5, Fischetti & Lodi 2003) + 무작위 고정(1/5) + RINS 결합 |
| **4순위** | SC 2/3-Flip & 동적 행 가중치 타부 탐색 | `src/core/sc_solver.cpp` | 행별 축소 후보 목록(`build_rcand`, 비용 오름차순 정렬·10% 변경 시 재구축); 정밀 `1-drop/{1,2}-add + drop-redundant` (`improve_flip`, 부가 제약 `fits_add` 준수); `O(col_len)` 증분 `p_loss`/`unc_list` 기반 동적 행 가중치 타부 탐색(`wls_step`, Yagiura, Kishida & Ibaraki 2006) — 순수 SC(`ns == 0`)에서 트리 포기 워커 2를 전담 배치하고 `want_help_tree()` 시 즉시 B&B 합류, 부가 제약 `dms`(`ns > 0`)는 패스당 1회 `S.best` 2/3-flip 정련 |
| **테스트·문헌** | 단위 테스트 & 클린룸 출처 | `tests/test_lp.py`, `tests/test_p6.py`, `docs/references.md` | `-Wall -Wextra -Wpedantic -Werror` 빌드 통과, 단위 테스트 **180/180 통과**(P5 170 → +10건), 추가 인용 5건 Crossref/DOI 대조 완료 |
